Bem-vindo ao repositório do meu portfólio profissional. Este projeto foi desenvolvido com foco absoluto em **alta performance**, **arquitetura limpa** e **design premium**, refletindo a minha abordagem na criação de soluções digitais corporativas e seguras.

## 🚀 Sobre o Projeto

O portfólio atua como um cartão de visitas digital e uma vitrine técnica. Ele foi projetado para carregar de forma extremamente rápida, oferecer excelente acessibilidade e possuir uma estrutura de SEO avançada (preparada para captação de leads), atraindo clientes que buscam soluções avançadas como:
- Sistemas Web Corporativos (ERP, PDV, Sistemas de Gestão)
- Plataformas de E-commerce
- Aplicativos de Academia
- MVPs (Minimum Viable Products)
- Softwares com foco rígido em Segurança da Informação

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com as melhores e mais modernas ferramentas do ecossistema front-end:

* **[React 18](https://react.dev/)** + **[Vite](https://vitejs.dev/)** (Core & Bundler ultrarrápido)
* **[TypeScript](https://www.typescriptlang.org/)** (Tipagem estática e prevenção de erros em tempo de compilação)
* **[Tailwind CSS](https://tailwindcss.com/)** (Estilização utilitária e design responsivo)
* **[Motion / Framer Motion](https://motion.dev/)** (Animações complexas, físicas e fluídas)
* **[Lucide React](https://lucide.dev/)** (Ícones SVG modernos e leves)
* **[FormSubmit](https://formsubmit.co/)** (Integração serverless para envio direto de e-mails via formulário)

## ✨ Principais Funcionalidades

* 🎨 **Design "Glassmorphism" Premium:** Interface moderna com modo escuro nativo, efeitos de vidro translúcido, brilhos sutis e detalhes em neon ciano.
* ⚡ **Alta Performance & SEO Avançado:** Indexação otimizada com tags *Open Graph*, *Twitter Cards* e estruturação semântica de IA (JSON-LD Schema.org) com foco nas palavras-chave mais rentáveis do mercado corporativo.
* 📱 **100% Responsivo (Mobile-First):** Experiência de usuário fluida e milimetricamente ajustada para rodar em smartphones, tablets e monitores ultrawide.
* 📧 **Formulário de Contato Inteligente:** Sistema seguro de envio direto para a caixa de e-mail sem recarregar a página e sem depender de backend externo (protegido contra bots).

## ⚙️ Como rodar o projeto localmente

Siga os passos abaixo para testar o ambiente de desenvolvimento na sua máquina:

1. Clone este repositório:
   ```bash
   git clone https://github.com/Adonis071/NOME-DO-SEU-REPOSITORIO.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd NOME-DO-SEU-REPOSITORIO
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Acesse no seu navegador: `http://localhost:3000`
